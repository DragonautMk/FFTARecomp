Mostra i comandi

Windows, con Docker Desktop già usato per la coverage:

.\scripts\windows\report_home.ps1 -OpenReport

Linux, con la stessa immagine Docker:

bash scripts/linux/report_home.sh

In alternativa, con Python 3 già installato:

python3 scripts/report_home.py

I comandi aggiornano solo questo indice. Non rigenerano la coverage e non eseguono il gioco. I link ai file rimangono relativi; dopo aver spostato singoli report, rigenera l’elenco.
