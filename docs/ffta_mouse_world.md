# Experimental desktop mouse input

Mouse input remains off by default. Input / Mouse and Keyboard activates it
and selects an independent, persisted set of ten keyboard bindings. Directions
default to WASD, GBA L/R to Q/E; the Keyboard profile retains its original keys.
Gamepad detection does not overwrite either set of keyboard bindings.
Keyboard and Mouse and Keyboard are mutually exclusive keyboard profiles.
Fast-forward and zoom shortcuts remain shared. The original desktop cursor
asset is assets/cursor.png, generated by scripts/generate_cursor.py.

## Attack confirmation

MEDIDO: USA Thumb 08029350 and EUR Thumb 0802A58C implement the binary
confirmation. Up/down toggles cursor+11, then updates its position from the
two records at owner+80/+88. A accepts selected+1, B cancels. The confirmation
has no ordinary text-list pointer or choice count, unlike battle actions.
Detection checks the exact supported ROM, a short function signature, task
type 10, live cursor callback, null list pointer, row records and visible OAM.
Mouse navigation feeds original buttons and waits for the selected row before
confirming. No attack result or ROM bytes are replaced.

## World map

MEDIDO in EUR: IWRAM 03002810 points to the current manager; manager+4 points
to the logical cursor. Halfwords +6/+8 are world X/Y, +C is vertical scroll.
The derived sprite in 0201997C is not the navigation state.

MEDIDO by disassembly: original bounds are X 14..224 and world Y 22..330.
The adapter checks short entry/store signatures, live map BG registers and
cursor flags, converts native mouse Y using the live scroll, and changes only
r0 at the original coordinate stores. Both stores remain interpreted while
the virtual directional input is being released, preventing a one-pixel drift.
Recorded world targets occupy mouse IDs 4096..42495. Original A runs after
publication; the original cursor flag bit 1 disables aiming until free control returns.
Flag 0x61 at a visitable destination remains mouse-addressable, like flag 0x41.

## Finite world map margins

The paired BG0/BG1 registers AA03/AC02 identify the world map planes (256x512).
With the verified ROM background patch active, horizontal margins read only the
finite plane using signed HOFS. They neither wrap nor stretch the last pixel.
The native 240px viewport retains original hardware sampling. FFTA_BG_EDGE=wrap
restores the previous margin behavior for comparison. Battle planes are unchanged.
